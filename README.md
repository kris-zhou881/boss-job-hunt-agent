## 摘要

硬门槛命中则直接跳过、不打分：

- JD 明确要求「英语口语流利/可直接与客户英文沟通」
- JD 明确要求「四级及以上」且写明「必须」
- JD 明确要求「1年以上外贸经验」且写明「必须」
- 低质量销售：纯电话销售（保险/贷款/理财/教培/网贷）、无底薪纯提成、「交押金/买产品/培训费」，以及只写「高薪轻松月入过万」却不写具体业务

打分三档只决定优先级和话术，不能代替硬门槛：

- **A 档（≥75）**：当天投，个性化打招呼
- **B 档（55–74）**：标准话术投
- **C 档（<55）**：不投

工厂型外贸恢复纳入，仍按具体 JD 做硬门槛核验和真实打分。硬门槛未知或未通过时，不得因分数高而当作可投或待遇已合格。

投递节奏：每天 30–40 个，分上午、下午、晚上；每次间隔随机 10–60 秒。间隔只用于降低操作频率，不能绕过平台限制、风控、验证码或安全墙。已投递公司自动去重，不重复打招呼。每天 30–40 个是节奏目标，不是必须凑满的定额。

每周按外贸 / 跨境 / 销售 / 运营统计投递数、回复数、面试数；回复率最高的类型下周多投。A 档回复率低于 5% 时，再评估是否下调阈值或检查简历关键词。

简历只写真实经历，并与面试口径一致。原文里的淘宝、拼多多、小红书、抖音、直播等字样是投递规则，不能自动当成新确认履历。核实稿、打招呼、正式投递、附件和联系方式，须当轮明确批准后才能发出。

城市、底薪、作息、排除项，以及该用户当前的 09:30 / 15:30 / 19:30 三个时段，写在规则文件的实施说明里。
