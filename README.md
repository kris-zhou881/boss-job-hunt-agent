# BOSS 直聘分层投递规则

本仓库维护 BOSS 直聘求职技能，以及 2026-11-21 生效的分层投递规则 v2。

- 技能入口：[SKILL.md](SKILL.md)
- 规则全文：[references/job_search_rules_v2_20261121.md](references/job_search_rules_v2_20261121.md)
- 授权例子：[references/authorization-mode-examples.md](references/authorization-mode-examples.md)

分层打分和硬门槛以规则全文第一节为准。是否逐家确认，由技能按当前用户的有效范围决定。规则文件第二节是 2026-11-21 的个人配置记录，只约束那份记录里的用户，不是所有使用者的通用限制，也不是常设发送授权。

默认是复核模式：核实稿、打招呼、正式投递、附件和联系方式，逐项批准后再发出。当前用户的已保存指令里写明精确常设发送授权时，才在该范围内用已有真实简历自动投递，不再逐家确认。约面试、排期和承诺始终要用户确认。对话里的同意不写进技能模板，也不自动给定时任务或监听任务。

## 摘要

硬门槛命中则直接跳过、不打分：

- JD 明确要求「英语口语流利/可直接与客户英文沟通」
- JD 明确要求「四级及以上」且写明「必须」
- JD 明确要求「1年以上外贸经验」且写明「必须」
- 低质量销售：纯电话销售（保险/贷款/理财/教培/网贷）、无底薪纯提成、「交押金/买产品/培训费」，以及只写「高薪轻松月入过万」却不写具体业务

打分三档只决定优先级和话术，不能代替硬门槛：

- **A 档（≥75）**：当天投，个性化打招呼
- **B 档（55–74）**：标准话术投
- **C 档（<55）**：不投

工厂型外贸恢复纳入，仍按具体 JD 做硬门槛核验和真实打分。硬门槛未知或未通过时，不得因分数高而当作可投或待遇已合格。

投递节奏：每天 30–40 个，分上午、下午、晚上；每次间隔随机 10–60 秒。间隔只用于降低操作频率，不能绕过平台限制、风控、验证码或安全墙。已投递公司自动去重，不重复打招呼。每天 30–40 个是节奏目标，不是必须凑满的定额。

每周按外贸 / 跨境 / 销售 / 运营统计投递数、回复数、面试数；回复率最高的类型下周多投。A 档回复率低于 5% 时，再评估是否下调阈值或检查简历关键词。

简历只写真实经历，并与面试口径一致。原文里的淘宝、拼多多、小红书、抖音、直播等字样是投递规则，不能自动当成新确认履历。未知不能当成已合格。

只有平台回执明确显示简历申请已经提交，才计为一次投递。打招呼、只发起沟通和结果不明的操作都不计入，也不为了补回执再发一次。被屏蔽、已拒绝或状态不明的公司不再联系。一条被登录、验证码或缺少事实挡住时，跳过这一条，继续其他仍在范围内的工作。

固定底薪门槛可以从当前用户的范围里明确取消。规则文件第二节里的金额、城市和时段是那份个人记录，技能模板不内置这些值。
