# 简历定向优化

仅在为具体 JD 生成、修改或核验简历时读取。

## 流程

按 `Resume → JD → Gap → Evidence → Rewrite → Verification` 执行：

1. 提取 JD 的核心任务、硬条件、关键词和岗位层级。
2. 对照事实库，区分已证实优势、可补强差距和未知项。
3. 仅用证据充分的事实重写个人优势、职责、项目、技能与空窗期。
4. 每条输出使用 `原文 → 修改建议 → 修改原因`，并标出待确认事实。
5. 在 BOSS 在线简历写入前，展示完整文本、简历版本名和影响范围，获得用户确认后再操作。
6. 写入后重新读取页面，确认已保存且未覆盖无关经历。

## 证据强度

- A：用户确认且有可核验成果或材料；可写具体数字。
- B：用户确认但没有量化材料；可写职责，不夸大结果。
- C：有间接线索；只能提问或写学习计划。
- D：无证据；不得写入。

## BOSS 简历版本

为每个 JD 使用清晰版本名，例如 `外贸业务员｜公司简称｜日期`，记录关键词覆盖、改动点和事实来源。优先保证 HR 十秒扫描能看到：目标岗位、最相关经历、核心技能、可验证成果和到岗状态。

Keyword Coverage 只统计事实支持的 JD 关键词；不要为了覆盖率堆砌工具或平台名。
