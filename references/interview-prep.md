# 面试准备

仅在用户要求某岗位的面试题、回答框架或反向提问时读取。

## 出题逻辑

按 `Confirmed 用户经历 + JD 每条要求 + 公司产品/业务 + 岗位层级 + 空白期风险点` 生成，不按职位名称套题。先读取 [user-facts.md](user-facts.md)，涉及空白期时再读取 [career-gap.md](career-gap.md)。

覆盖 HR 面、业务面、专业面、压力面；每题给出追问链、真实回答框架和必须由用户补充的事实。

```text
问题：…
高概率追问：… → … → …
回答框架：背景 / 目标 / 做法 / 结果 / 复盘
可用事实：…
待确认或诚实说明：…
```

反向提问按对象分组：

- HR：合同、试用期、社保、薪酬构成、加班、离职原因；
- 直属领导：团队规模、岗位边界、前三个月目标、KPI、资源和协作；
- 业务：客户、产品、市场、获客、增长、回款与提成口径。
