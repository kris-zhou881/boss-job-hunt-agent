# 浏览器与平台恢复

仅在 BOSS 页面打不开、闪退、白屏、登录失效、元素缺失或触发风控时读取。

## 场景处理

| 场景 | 动作 |
| --- | --- |
| 页面未加载或关键元素未出现 | 等待关键元素；不以固定短等待代替状态确认 |
| 标签页关闭、变成空白或控制失效 | 重新读取现有标签；无可用标签时请用户在已登录 Chrome 重新打开 BOSS |
| 登录页、验证码、安全验证 | 停在页面，请用户登录或完成验证 |
| 单次导航或点击无效 | 读取最新 DOM/页面状态后仅重试一次 |
| 同类操作连续两次失败 | 进入 `PLATFORM_RISK_PAUSE`，报告页面、动作和可见错误；不循环重试 |

## BOSS 闪退专项

1. 判断是否出现在高频搜索、连续投递或多标签操作后；若是，按平台风控暂停，不把它当纯技术故障。
2. 保持单标签、单会话、低频操作；不要并发读取多个详情页。
3. 先确认 Chrome 与浏览器控制连接正常、资源充足、无积压标签页；不要自行修改系统或浏览器安全设置。
4. 每次点击前读取页面，等待目标元素可见；聊天面板和推荐列表需按实际加载状态操作。
5. 崩溃后只恢复一次；同类动作第二次失败即 Ask User。点击类操作可降级为用户人工完成，Agent 只做读取、评估和文案准备。

不使用伪装、绕过或规避 BOSS 限流和安全机制的方法。
