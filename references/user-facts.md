# 用户事实库

仅在改简历、生成打招呼文案、面试准备或评估差距时读取。

## User Fact Ledger

维护可追溯的事实条目：`事实｜类别｜来源｜状态｜可用于哪些输出｜确认日期`。

状态只有三种：

- `Confirmed`：用户明确确认，或简历/作品中有可核验原文；可用于简历、沟通和回答。
- `Inferred`：由现有材料推断；只能作为待确认问题，不能写成事实。
- `Unknown`：没有证据；不能补写、不能暗示具备。

类别包括：经历、职责、成果数据、工具、语言、行业、到岗、薪资、地点偏好、空窗期、求职限制。

每次写入简历、打招呼或回答前，回查事实库；数字、客户、平台账号、证书和业绩必须有 `Confirmed` 来源。不要把“可学习”“参与过”升级为“独立负责”。

若把简历写入本地匹配工具，`Inferred` 和 `Unknown` 的技能名只放在独立事实清单，不放进会被送去打分的简历正文；否则关键词匹配可能把“未使用过 SB/SD”误算作具备 SB/SD 经验。保留来源与待核实标记，但不在简历正文列举未证实的工具或平台名称。
